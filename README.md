# Student-Management-System
Student Management System built in Java to manage student details, subject marks, percentage calculation, and result generation.

Features: Student Details Management, Subject Marks Entry, Total Marks Calculation, Percentage Calculation, Result Generation.
Concepts Used: Scanner, Variables, Arithmetic Operations, Conditional Statements (if-else), User Input Handling.
Future Improvements: Grade Calculation, Multiple Student Records, Data Storage, Input Validation, Database Integration.
